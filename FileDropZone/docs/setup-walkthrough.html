Before you start

  • You need the System Administrator or System Customizer role in the environment.
  • Only if you build the solution yourself: pac CLI (Power Platform CLI, recent version), Node.js and the .NET SDK (for dotnet build).
  • Decide which table gets the control, for example Account, Case, or one of your own.

Labels on the illustrations follow the current Power Apps maker portal. Microsoft moves things around now and then, so a button may sit in a slightly different place, but the names stay the same.

1

Get the solution file

Open the Releases page, pick the latest File Drop Zone release and download ArtFileDropZone_managed.zip under Assets. That's the file you import in step 2.

Prefer to build it yourself? You need the pac CLI and the .NET SDK. In the FileDropZone folder of this repository run:

npm ci
dotnet build Solution\FileDropZoneSolution.cdsproj -c Release

Build succeeded.
  -> Solution\bin\Release\FileDropZoneSolution.zip (managed)

Want a quick try in a dev environment instead? Run pac auth create --environment https://yourorg.crm.dynamics.com then pac pcf push --publisher-prefix art in the FileDropZone folder, and skip to step 3.

7

Save, publish and check it

  1. Click Save and publish (top right of the form designer). Wait for "Published".
  2. Open your app, then an existing record of that table, and go to the Documents tab. Press Ctrl+F5 once so the browser picks up the new control. You should see the drop area like the first screenshot above, plus any files already attached to the record.
  3. Drop a small PDF. It should appear in the list and in the Timeline (after refreshing it).
  4. Open + New for that table. You should see "Save the record to add files."
  5. Optional checks:
    • Drop a file over the limit. It should be refused with the limit in the message.
    • Drop a .exe. It should be refused as blocked.

The properties, and when to change them

PropertyLeave asWhat it does / when to change it
Host field(set for you)The text column from step 4b. The control never writes to it.
Allowed file typesemptyEmpty = every type the environment allows. Type a list such as .pdf, .docx, .jpg to allow only those on this form. The environment's blocked list always wins.
Max file size (MB)emptyEmpty = the environment's limit (see the step 3 table). Set a number only to be stricter on this form, e.g. 2.
Max files per drop10How many files one drop, paste or browse can add. Extra files are left out with a message.
Note titleemptyThe title of each note. Empty = the file name. Type e.g. Customer document to use the same title for all.
Show existing attachmentsYesNo = upload only; the list (and preview, download, delete) is hidden.
Allow deleteYesNo = no delete button. Users' security roles still apply either way.
Show image thumbnailsYesNo = plain icons instead of small pictures. Each image is downloaded once to draw its thumbnail, so turn it off on records with many large photos.

What users need: permission to create notes and append them to the record, the same as attaching a file in the Timeline. Standard roles like Salesperson and Customer Service Representative already have this.

If something isn't right

The control isn't in the + Component list.Use Get more components in that panel. If it's not there either, the import in step 2 didn't finish, or you're in a different environment.
I still see a text box, not the drop zone.The form wasn't published, or the browser has the old form. Click Save and publish, then press Ctrl+F5 on the record. Also check that Web is ticked in step 6.
"Save the record to add files."Normal on a new record. Save it once and the drop zone turns on.
"… files are blocked by your organization."That type is on the blocked list or the MIME rules from step 3. Remove it there if it should be allowed.
Files over a few MB are refused.The environment's limit is low. With the default 5,120 KB, files over 3.7 MB are refused. Raise it in step 3, and check the form's "Max file size" is empty.
An upload fails with a permission message.The user's security role can't create notes or append to this record. Fix it in their role.
The PDF preview is blank.Some environments have a security policy that blocks PDFs inside the page. Use Download instead, and open an issue so the PDF preview can be switched to the platform viewer.
New files don't show in the Timeline.The Timeline doesn't know about the upload. Click its refresh button.

Installing a newer version later

Download the newer ArtFileDropZone_managed.zip from the Releases page (or, for your own build, raise the version in ControlManifest.Input.xml and build again) and import it as in step 2; Power Apps offers an Upgrade. The forms that use the control pick it up on their own. If you set up 0.1.0 earlier, open that form once and clear the old "Max file size" of 5, so the environment's limit applies.
